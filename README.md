# ARviewerOL-visor

El visor de maquetas en realidad aumentada de Ortiz.Leon Arquitectos.

Los modelos de `m/` están **cifrados** (AES-256-GCM). La clave de cada uno va
solo en su código QR y no está en este repositorio: sin el QR, un modelo es
ruido. Lo que se publica es la maqueta ligera (triángulos y colores), nunca el
modelo de Revit.

Se publica desde ARviewerOL; no se edita a mano.
